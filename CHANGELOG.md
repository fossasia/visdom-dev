# Changelog

Versions follow [semantic versioning](https://semver.org). Nothing so far is a
breaking change, so only the last two numbers move:

- **Minor** (0.x.0): a large feature that brings several smaller ones with it.
- **Patch** (0.0.x): a smaller feature, a small addition, or a bug fix.

## 0.1.0

The starting point for version numbers. It covers everything in the repository
up to this entry: the gateway, the console, the proxy and the deployment files.
